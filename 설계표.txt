서버 이름: Todo
한 문장 설명: 나는 할 일을 추가·조회·완료·수정·삭제할 수 있는 MCP 서버를 만든다.

[Tool]  모델이 필요할 때 실행하는 동작
 1) 이름: add_todo        입력: title (str)                                  결과: 새로 만든 할 일 (id, title, done=false, created_at)
 2) 이름: list_todos      입력: status ("all" | "open" | "done", 기본 "all")   결과: 조건에 맞는 할 일 목록 (비어 있으면 빈 목록)
 3) 이름: complete_todo   입력: todo_id (int)                                결과: done=true로 바뀐 할 일
 4) 이름: update_todo     입력: todo_id (int), title (str)                   결과: 제목이 바뀐 할 일
 5) 이름: delete_todo     입력: todo_id (int)                                결과: "id N 할 일을 삭제했습니다" 안내 문구

[Resource]  앱이 맥락으로 읽어 가는 데이터
 1) 주소: todo://summary        내용: 전체/남은/완료 개수 요약 (예: "전체 5개 / 남은 것 3개 / 완료 2개")

[Prompt]  사용자가 직접 고르는 틀 (없어도 됨)
 1) 이름: plan_my_day     입력: 없음        요청하는 일: 남은 할 일 목록을 바탕으로 오늘 할 일의 순서와 계획을 세워 달라고 요청

실패할 수 있는 경우 (빈 입력, 없는 항목 등):
 - add_todo / update_todo: 제목이 비어 있거나 공백뿐인 경우 → ToolError("제목이 비어 있습니다")
 - complete_todo / update_todo / delete_todo: 없는 id인 경우 → ToolError("id N인 할 일이 없습니다")
 - complete_todo: 이미 완료된 할 일인 경우 → 오류 대신 "이미 완료된 할 일입니다" 안내 (또는 ToolError, 선택)
 - list_todos: status에 all/open/done 외의 값이 들어온 경우 → 입력 검증 실패 (Literal 타입으로 SDK가 자동 처리)
 - todos.json 파일이 없거나 비어 있는 경우 → 오류 없이 빈 목록으로 시작
 - todos.json 파일이 깨져 JSON으로 읽을 수 없는 경우 → ToolError("저장 파일을 읽을 수 없습니다")
